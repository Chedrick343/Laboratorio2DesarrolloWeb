# Aplicacion de los diferentes tipos de elementos.
## Selectores de tipo.
- Se aplicaron los selectores de tipo para secciones como section, nav, form, sin embargo se hicieron cambios especificos sobre
algunos de los elementos usando id o class.
## Selectores de clase
- Con los selectores de clase se usaron en su mayoría en ul, ol y li para poder hacer diferentes los elementos de las listas
y así dar mayor detalle a la página web.
## Selectores de id 
- Los selectores de id se usaron en muchos elementos, por ejemplo en la imágen de cristiano ronaldo, por defecto esa imágen era
algo pequeña, entonces la ajustamos con el id y así mantenía también los atributos indicados en el selector de atributo.
## Selectores de atributo
- Estos fueron usados para las imagenes, como todas tienen el atributo alt, entonces aprovechamos eso para colocar bordes redondeados
y además sombrado a las imágenes.
## Combinadores
- Realmente útiles para manejar la tabla, se logró implementar que todas las columnas de una fila al pasar el mouse sobre esta se resaltaran
en color azul para que el usuario no perdiera de vista la fila en la que se encuentr 
## Pseudo-clases de estado
- Usamos hover para la tabla, resaltar las filas sobre las que está el mouse y también para resaltar el botón de envío del formulario.
Además, cuando se presiona el botón de enviar el formulario, gracias a la Pseudo-clase de estado active, podemos ver como se vuelve en
un color verde.
## Pseudo-clases estructurales
- Estas Psudo-clases se utilizaron en la lista de premios para indicar cuál elemento iba en qué color, por ejemplo el primer hijo (que es 
el primer premio) en color dorado, el segundo, en plateado y el tercero en color similar al bronce.
## Overflow
- Se usó Overflow en la sección de ingenierías y exposiciones como es un apartado tan largo entonces se usó overflow auto para que no se
vea todo el contenido de una vez.
## Flexbox
- Se utilizó en nav para alinear todo el contenido de la página pero de manera vertical y no horizontal.
